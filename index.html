Animações curtas das aulas teóricas. Cada vídeo roda aqui no navegador, desenhado a partir do código e das equações das projeções: use a barra de tempo para avançar, voltar e pausar onde quiser.

Aula 08 · Projeções Conformes

Sete vídeos, de 50 s a 72 s.

Como estes vídeos são feitos

  • Geometria exata: curvas, reticulados e indicatrizes são calculados pelas equações (esfera ou elipsoide GRS80), nunca desenhados à mão.
  • Números conferidos: cada vídeo tem um script em Python que recalcula os valores mostrados na tela.
  • Sem arquivos de vídeo: o que você vê é o código rodando; cada instante é uma função do tempo.
Linhas de costa: Natural Earth 1:110m (domínio público).
