Projeções Cartográficas em movimento

Animações curtas das aulas teóricas, para ver em movimento o que é difícil de enxergar numa figura parada. Cada vídeo roda aqui no navegador, desenhado a partir do código e das equações das projeções: use a barra de tempo para avançar, voltar e pausar onde quiser.

Prof. Dr. Darlan M. Nunes · 2026

Como estes vídeos são feitos

  • Geometria exata: curvas, reticulados e indicatrizes são calculados pelas equações (esfera ou elipsoide GRS80), nunca desenhados à mão.
  • Números conferidos: cada vídeo tem um script em Python que recalcula os valores mostrados na tela e os compara com os slides.
  • Sem arquivos de vídeo: o que você vê é o código rodando; cada instante é uma função do tempo.

Contornos: Natural Earth 1:110m e 1:50m (domínio público). Trilha: “Ambient Piano Guitar Texture E”, de deadrobotmusic (Freesound, CC0).
